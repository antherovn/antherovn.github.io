# Portfólio bilíngue de Anthero Vieira Neto

## Objetivo
Criar uma página pessoal de alta credibilidade para apresentar Anthero como engenheiro de software sênior, conectando 18+ anos de trajetória, arquitetura, DevOps, IA aplicada e construção de produtos. A página será preparada para publicação no repositório `anthero/anthero` via GitHub Pages.

## Direção escolhida
- **Estilo:** editorial tecnológico, autoral e sóbrio — mais próximo de uma publicação de engenharia do que de um template de portfólio.
- **Paleta:** fundo claro levemente quente, texto quase preto, verde profundo como cor principal e dourado discreto para marcos.
- **Tipografia:** títulos editoriais com personalidade combinados a uma fonte técnica e muito legível no restante.
- **Composição:** hierarquia forte, bastante respiro, linhas e numeração editorial; projetos apresentados com imagens reais das interfaces, não ilustrações genéricas.
- **Movimento:** entradas sutis ao rolar, transições precisas e respeito à preferência de movimento reduzido.

## Estrutura da página
1. **Abertura**
   - Nome em destaque: “Anthero Vieira Neto”.
   - Posicionamento como engenheiro de software que transforma sistemas complexos em produtos utilizáveis.
   - Resumo curto de experiência e áreas de atuação.
   - Ações para ver projetos, abrir LinkedIn e acessar GitHub.

2. **Trajetória**
   - Linha do tempo concisa, baseada no LinkedIn e depois refinada pelos repositórios.
   - Ênfase na evolução entre engenharia, arquitetura, DevOps, IA aplicada e criação de produtos.
   - Números e resultados somente quando confirmados por fonte pública ou pelo próprio Anthero.

3. **Projetos selecionados**
   - Estudos de caso em destaque para MeuWatt, JuriSuit, Nexo, Thero e Mouraverse.
   - Athena, Zeus e Hunteradeck entram após acesso aos respectivos repositórios.
   - Cada projeto terá: problema, contribuição de Anthero, solução, tecnologias e link disponível.
   - Capturas reais dos produtos serão incorporadas quando públicas; projetos privados usarão uma composição tipográfica própria, sem simular telas inexistentes.

4. **Competências e forma de atuação**
   - Arquitetura de software, sistemas distribuídos, DevOps, IA/RAG, TypeScript, Python e Kubernetes.
   - Texto orientado a valor e tomada de decisão, sem virar uma lista extensa de ferramentas.

5. **Contato**
   - Fechamento direto com LinkedIn e GitHub.
   - Sem formulário ou armazenamento de dados nesta primeira versão.

## Português e inglês
- Português será o idioma inicial.
- Um seletor visível no topo alternará todo o conteúdo para inglês sem recarregar a página.
- Títulos, descrições, navegação, textos alternativos e metadados serão traduzidos de forma editorial, não literalmente.

## Conteúdo e fontes
- Usar o README enviado para o estudo de caso do JuriSuit.
- Usar as páginas públicas do MeuWatt, Nexo, Thero, Mouraverse e o LinkedIn como referências verificáveis.
- Após a conexão com GitHub, revisar os repositórios autorizados para confirmar escopo, autoria, tecnologias, imagens e resultados de cada projeto.
- Não publicar detalhes internos, segredos, métricas privadas ou trechos de código sensíveis.

## Implementação técnica
- Construir a experiência em uma única página responsiva, com navegação por seções.
- Criar componentes pequenos para abertura, trajetória, projetos, competências, idioma e rodapé.
- Organizar o conteúdo bilíngue em uma estrutura central para facilitar futuras atualizações.
- Usar imagens otimizadas e carregamento progressivo para manter a página rápida.
- Incluir título, descrição e metadados sociais próprios do portfólio.
- Configurar a saída estática e o caminho de assets para funcionar no GitHub Pages no repositório `anthero/anthero`.
- Validar visualmente em computador e celular, além de navegação por teclado, contraste, links e alternância de idioma.
